# Língua, território e futuro — ISLA

Apresentação em HTML e Vite, com a capa, os slides 09–11 e o bloco Linklado (página de transição e slides 19–23) reconstruídos a partir da apresentação-base. O projeto usa a identidade visual local em `referencias/assets/`; a pasta `referencias/` é um acervo e não contém código do projeto.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar uma versão estática:

```bash
npm run build
```

O conteúdo das telas está em `index.html`, a navegação do deck em `src/main.js` e os estilos em `src/style.css`. Use ←/→ ou PageUp/PageDown para navegar; um número no hash (`#2`, por exemplo) abre diretamente uma tela.
